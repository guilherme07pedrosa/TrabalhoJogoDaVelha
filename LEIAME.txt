TRABALHO 2 - Jogo da Velha distribuido (RMI + socket TCP + multicast)
Requer Java 17. NN = 04 (Registry 9804, multicast 225.1.1.4:8804).

ARQUIVOS
  MatchIntf.java       interface remota do Servidor de Match
  MatchImpl.java       Servidor de Match (cria o RMI Registry)
  TimeoutMatchEx.java  excecao: nenhum oponente no tempo limite
  Jogador.java         modulo jogador (RMI + TCP + multicast)
  Display.java         modulo display (multicast)
  Json.java            montagem e leitura das mensagens JSON

COMPILAR (na pasta dos .java)
  javac --release 17 *.java

USO
  java -Djava.rmi.server.hostname=<IP desta maquina> MatchImpl <portaRegistry> [timeoutSegundos]
  java Display [IP desta maquina]
  java Jogador <IP servidor> <portaRegistry> <meu IP> <minha porta> [humano|auto]
    humano (padrao): voce digita a casa
    auto           : joga sozinho na primeira casa livre (para testes)

PROBLEMAS COMUNS
  Display nao recebe nada: informe o IP da maquina (java Display <meu IP>)
  e use o IP real tambem nos Jogadores.

CONVENCOES
  - Mensagem: {"Numero", "Jogada", "Tabuleiro": [9 ints], "Resultado"}, uma por linha.
  - Tabuleiro: 0 = vazia, 1 = X (quem inicia), 2 = O.
  - Numero comeca em 0 e e incrementado por quem faz a jogada.
  - Quem recebe inicia=true conecta; o outro aceita a conexao.
  - Jogada invalida recebida: devolve a mesma mensagem, sem incrementar.
  - Fim: quem perde responde "der"; empate e respondido com "emp".
  - Cada jogador publica no multicast as proprias jogadas.
  - Timeouts: match 60s; jogada 5 min; aceite final 30s.
    5 rejeicoes seguidas encerram a partida.
